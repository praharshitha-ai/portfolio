# Portfolio

My personal site. It covers my clinical training in cardiac perfusion, my healthcare product and analytics work, selected projects, and certifications.

**Live:** https://prahashitha-portfolio.netlify.app

The whole site is one `index.html` file with its CSS and JavaScript inline, so there's no build step. Fonts are Fraunces and Inter from Google Fonts. To view it locally, open `index.html` in a browser.

Sections: about, clinical experience, education, projects, skills, certifications and contact.
